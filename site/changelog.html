Changelog

Public releases of mwfl and the capabilities introduced by each one.

Production Foundation baseline · August 2026

0.2.0

mwfl 0.2.0 turns the provisional Foundation slices into one coherent baseline for GUI, CLI, Windows Service, and supervised worker applications.

Highlights

  • Monotonic deadlines, stop-token cancellation, structured outcomes, and contextual native errors.
  • Job-based process supervision, bounded concurrent output, secure cancellable local Named Pipe IPC, and shared console/SCM service logic.
  • Thread-safe diagnostic fanout, ETW, Event Log, minidumps, secure buffers, credentials, and Windows identity helpers.
  • Recovery, version and Authenticode inspection, verified update handoff, and an independent Task Scheduler component.
  • 62 compiled examples plus nine standalone organization applications validated against the same release.

Release notes and the VS2026/MSVC x64 download.

Foundation release train · August 2026

0.1.9

mwfl 0.1.9 completes the backward-compatible 0.1.1-0.1.9 Foundation train while preserving the independently acquired UI layer.

Highlights

  • Core errors, results, handle ownership, Unicode conversion, cancellable waits.
  • Opt-in Service, child-process, bounded local IPC, diagnostics, security, and deployment components.
  • Nine runnable Foundation examples, including a controller/worker integration stack.
  • 54 compiled examples in total, independent public-header probes, and installed-package consumers.

Development-train notes.

First public preview · August 2026

0.1.0

mwfl 0.1.0 establishes the first supported public-preview baseline for building native Windows desktop applications with C++20.

Highlights

  • WTL/ATL-free real HWND windows and native control wrappers with typed events and explicit ownership.
  • DPI-aware row, column, and overlay layout using device-independent units.
  • Menus, accelerators, dialogs, clipboard, file drops, window placement, appearance, and accessibility helpers.
  • Safe worker-to-UI wakeups, timers, and wait-aware message pumping.
  • Visual Studio 2022 and 2026 support across x64 and ARM64 using the Microsoft Visual C++ compiler.
  • 45 compiled examples, CMake packages, copyable starters, and coding-agent-oriented guidance and evaluations.

Release notes and the VS2026/MSVC x64 download. Source builds and CI also cover ARM64; no ARM64 binary package is published for this preview.
