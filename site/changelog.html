First public release · August 9, 2026

0.1.0

mwtl 0.1.0 establishes the first supported public baseline for building native Windows desktop applications with C++20.

Highlights

  • Real HWND windows and 27 native control wrappers with typed events and explicit ownership.
  • DPI-aware row, column, and overlay layout using device-independent units.
  • Menus, accelerators, dialogs, clipboard, file drops, window placement, appearance, and accessibility helpers.
  • Safe worker-to-UI wakeups, timers, and wait-aware message pumping.
  • Visual Studio 2022 and 2026 support across x64 and ARM64 using the Microsoft Visual C++ compiler.
  • 31 runnable examples, CMake packages, copyable starters, and coding-agent-oriented guidance and evaluations.
