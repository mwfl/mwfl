Changelog

Public releases of mwfl and the capabilities introduced by each one.

Foundation update · August 13, 2026

0.1.3

mwfl 0.1.3 makes mwfl::ui the sole UI target and adds compiled CLI examples plus the Windows application foundation roadmap.

  • Removes the former generic CMake target so the UI component has one unambiguous public name.
  • Adds Unicode CLI command and cooperative worker examples.
  • Defines GUI, Windows Service, and CLI host boundaries and the opt-in foundation roadmap.

Release notes and the VS2026/MSVC x64 download.

0.1.2

mwfl 0.1.2 adds automatic system dark-mode propagation, improves native GroupBox rendering, and clarifies retained versus raw HWND appearance APIs.

  • Automatically reapplies frame, menu, native-control, and custom-drawing appearance after Windows theme changes.
  • Adds a populated live Appearance example and improves dark GroupBox captions.
  • Standardizes examples on SetAppearance() and names the raw HWND helper ApplyWindowAppearanceBestEffort().

Release notes and the VS2026/MSVC x64 download.

0.1.1

mwfl 0.1.1 improves release reliability and makes the example catalog easier to navigate.

Highlights

  • Moves Markdown Editor, PDF Reader, Folder Compare, and SQLite Viewer into focused standalone repositories.
  • Includes 45 compiled canonical examples and links six standalone applications from the documentation.
  • Mirrors pinned Scintilla 5.6.5 assets with SHA-256 verification and CI caching.
  • Adds bounded, verbose optional-component tests so stalled jobs fail with actionable diagnostics.

Release notes and the VS2026/MSVC x64 download.

First public preview · August 9, 2026

0.1.0

mwfl 0.1.0 establishes the first supported public-preview baseline for building native Windows desktop applications with C++20.

Highlights

  • Real HWND windows and 27 native control wrappers with typed events and explicit ownership.
  • DPI-aware row, column, and overlay layout using device-independent units.
  • Menus, accelerators, dialogs, clipboard, file drops, window placement, appearance, and accessibility helpers.
  • Safe worker-to-UI wakeups, timers, and wait-aware message pumping.
  • Visual Studio 2022 and 2026 support across x64 and ARM64 using the Microsoft Visual C++ compiler.
  • 45 compiled examples, CMake packages, copyable starters, and coding-agent-oriented guidance and evaluations.

Release notes and the VS2026/MSVC x64 download. Source builds and CI also cover ARM64; no ARM64 binary package is published for this preview.
