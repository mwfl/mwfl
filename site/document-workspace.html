Keep ownership explicit

DocumentWorkspaceModel owns metadata snapshots only. Text, undo buffers, file stamps, and page destruction remain application-owned by DocumentId. Native tab data stores an integer ID, never a pointer.

Transfer without loss

TransferDocumentWithPage accepts destination metadata before reparenting the page and removing source ownership. Failure restores metadata and HWND parentage.

Restore defensively

Sessions are versioned, bounded, and atomically replaced. Application validators classify missing, changed, or untrusted paths before content callbacks run.

Close only after every decision

Inspect both windows, collect Save/Discard/Cancel decisions, finish saves, then commit closes. Cancellation never tears down one workspace early.
