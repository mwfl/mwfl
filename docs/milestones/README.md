# Milestone acceptance records

These files are executable project contracts, not aspirational release notes.
The active milestone must have a detailed checklist. A later milestone is
expanded before implementation begins, after the preceding reflection gate has
passed.

The canonical milestone state and dependency order live in
[`docs/parity.json`](../parity.json).

The numbered files `0.2.md` through `0.8.md` are historical capability
milestones that shipped together in the `v0.1.0` public baseline. The latest
completed release milestone is [`0.1.1.md`](0.1.1.md), which covers ecosystem
and source compatibility rather than repeating the historical SDI milestone.
No subsequent release milestone is active until its acceptance contract is
approved.
