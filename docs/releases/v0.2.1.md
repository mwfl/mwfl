## mwfl 0.2.1

mwfl 0.2.1 hardens the 0.2 Foundation baseline and adds a shared,
application-facing update-check capability for the organization applications.

### Application support

- Adds `mwfl::app`, the default zero-overhead CMake facade for complete desktop
  applications. The precise `mwfl::ui` target remains available.
- Adds `mwfl::app_support::UpdateChecker` to `mwfl::app`/`mwfl::ui` with bounded
  GitHub Release checks, once-per-day automatic checks, three-day and one-week
  reminder choices, and a user-controlled automatic-check setting.
- Update checks only open the official GitHub Release page after confirmation;
  MWFL does not download or replace application binaries.
- All eight public organization applications and the private Rho PDF application
  consume this implementation directly instead of carrying copied code.

### Foundation and maintainability

- Process output collection now applies one monotonic deadline while draining
  stdout and stderr, including descendants that retain inherited handles.
- Foundation delay paths use stop-aware native waits instead of polling sleeps.
- Large production reference examples are split into focused application units.
- Independent-header, compile-cost, and target-size budgets guard against
  accidental coupling and renewed monolithic growth.
- Repeatable coding-Agent blind evaluations provide a durable usability baseline.

### Release engineering

- Release packages are built and attested for x64 and ARM64 with MSVC-only
  workflows aligned to the Windows product boundary.
- Public catalogs contain only public applications; private repositories remain
  excluded from public documentation.

### Downloads

- `mwfl-0.2.1-AMD64.zip` and `mwfl-0.2.1-ARM64.zip`: installed CMake package,
  libraries, public headers, documentation, and notices.
- `mwfl-notepad-0.2.1-windows-x64.zip` and
  `mwfl-notepad-0.2.1-windows-arm64.zip`: portable Notepad reference application.
- `SHA256SUMS-x64.txt` and `SHA256SUMS-arm64.txt`: SHA-256 checksums.

The x64 package is validated with VS2026/MSVC. ARM64 is built and tested on the
native GitHub-hosted Windows ARM runner using the supported MSVC toolchain.
