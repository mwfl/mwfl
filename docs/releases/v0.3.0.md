## mwfl 0.3.0

mwfl 0.3.0 adds an opt-in, privacy-conscious minidump tier for applications
that need richer crash triage without collecting broad process memory.

### Diagnostics

- Adds `mwfl::diagnostics::MiniDumpKind::WithThreadInfo`.
- Maps the new tier to Windows `MiniDumpWithThreadInfo`.
- Keeps `MiniDumpKind::Small` as the default and leaves broader dump capture an
  explicit application decision.
- Updates the native diagnostics example and public API catalog.

### Compatibility

- The change is source-compatible with existing 0.2 applications.
- Templates and maintained consumer examples pin the immutable `v0.3.0` tag.

### Downloads

- `mwfl-0.3.0-AMD64.zip` and `mwfl-0.3.0-ARM64.zip`: installed CMake package,
  libraries, public headers, documentation, and notices.
- `mwfl-notepad-0.3.0-windows-x64.zip` and
  `mwfl-notepad-0.3.0-windows-arm64.zip`: portable Notepad reference application.
- `SHA256SUMS-x64.txt` and `SHA256SUMS-arm64.txt`: SHA-256 checksums.

The x64 package is validated with VS2026/MSVC. ARM64 is built and tested on the
native GitHub-hosted Windows ARM runner using the supported MSVC toolchain.
