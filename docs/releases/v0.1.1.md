## mwfl 0.1.1

This reliability update keeps the first public-preview API baseline intact while
making the project easier to evaluate and the release pipeline more dependable.

### Highlights

- Moved Markdown Editor, PDF Reader, Folder Compare, and SQLite Viewer into
  focused standalone repositories in the mwfl organization.
- Kept 43 compiled canonical examples in the core repository and updated the
  documentation and capability catalog to link the standalone applications.
- Mirrored the pinned Scintilla 5.6.5 source and runtime archives with unchanged
  SHA-256 verification, an official-source fallback, and GitHub Actions caches.
- Added bounded, verbose optional-component tests so stalled jobs terminate with
  actionable diagnostics.

### Packages

- `mwfl-0.1.1-AMD64.zip`: CMake package and installed public files for
  VS2026/MSVC x64.
- `mwfl-notepad-0.1.1-windows-x64.zip`: standalone Notepad reference application.
- `SHA256SUMS-x64.txt`: SHA-256 checksums for both ZIP packages.

Source builds and CI continue to cover x64 and ARM64 with Visual Studio 2022 and
Visual Studio 2026. An ARM64 binary package is not published in this preview.
