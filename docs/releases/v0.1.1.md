## mwfl 0.1.1

The first compatibility and ecosystem update to the `v0.1.0` public baseline.
This release preserves the stable 0.1 API and strengthens evidence that MWFL
works as a maintained dependency across real Windows applications.

### Highlights

- Freezes the complete `v0.1.0` installed public-header set as a
  machine-verified source-compatibility baseline.
- Adds a dedicated downstream workflow that builds and tests Folder Compare,
  Folder Explorer, Hex Editor, Markdown Editor, Notepad::, PDF Reader, SQLite
  Viewer, and Startup Manager against each candidate MWFL commit.
- Keeps installed-package, `FetchContent`, and `add_subdirectory` consumers as
  required package gates for every exported component.
- Organizes the 62 compiled examples into starter, focused, catalog, composed,
  advanced, and reference learning paths without moving their stable sources.
- Makes full ARM64 verification run both Debug and Release configurations.
- Resolves project-owned MSVC static-analysis findings in update request header
  sizing, monitor placement recovery, and the splitter notification constant.

### Compatibility

- Stable `v0.1.0` source remains supported; no stable public API was removed.
- ABI compatibility across MSVC toolsets or runtime configurations is not
  promised. Rebuild MWFL and the application with the same supported toolset.
- Consumer templates and current installation guides pin `v0.1.1`.

### Packages

- `mwfl-0.1.1-AMD64.zip`
- `mwfl-0.1.1-ARM64.zip`
- `mwfl-notepad-0.1.1-windows-x64.zip`
- `mwfl-notepad-0.1.1-windows-arm64.zip`
- `SHA256SUMS-x64.txt` and `SHA256SUMS-arm64.txt`

provenance attestations.
