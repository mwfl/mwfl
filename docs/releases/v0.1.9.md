## mwfl 0.1.9

The 0.1.1-0.1.9 release train expands mwfl from its native UI layer into an
independently acquired Windows application foundation.

- `mwfl::core`: explicit errors/results, handle ownership, Unicode conversion,
  cancellable waits;
- `mwfl::service`: Service lifecycle, console debugging, SCM dispatcher;
- `mwfl::process`: quoted process launch, non-inherited handles, wait and exit;
- `mwfl::ipc`: bounded local Named Pipe frames;
- `mwfl::diagnostics`: structured events, redaction, debug and bounded files;
- `mwfl::security`: current-user DPAPI with cleared plaintext buffers;
- `mwfl::deployment`: package identity and scoped restart registration;
- nine runnable examples, one for every 0.1.1-0.1.9 delivery slice.

All components remain opt-in. `mwfl::ui` does not implicitly start a Service,
child process, IPC server, diagnostic sink, security store, or deployment action.
