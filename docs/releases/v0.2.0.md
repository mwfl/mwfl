## mwfl 0.2.0

mwfl 0.2.0 establishes the next public-preview compatibility baseline for
native GUI, CLI, Windows Service, and supervised worker applications. It keeps
the UI layer independent while productionizing the opt-in Foundation
components introduced during the 0.1.x train.

### Foundation baseline

- Core operations use monotonic deadlines, `std::stop_token` cancellation,
  structured timeout/cancel/disconnect outcomes, and contextual native errors.
- Process supports structured environments, redirected standard streams,
  suspended Job Object assignment, bounded concurrent output collection,
  graceful console stop, and process-tree termination.
- IPC uses pre-created local Named Pipe listeners, overlapped cancellation,
  bounded framing, current-user security by default, remote-client rejection,
  peer identity, and scoped impersonation.
- Service shares one application context between console and SCM hosts and adds
  typed controls plus explicit idempotent management operations.
- Diagnostics adds thread-safe multi-sink fanout, pre-sink redaction, rotation,
  TraceLogging ETW, explicit Event Log source management, and opt-in minidumps.
- Security adds fixed-allocation secure buffers, Credential Manager, token and
  SID inspection, integrity/elevation queries, and focused security descriptors.
- Deployment adds Application Recovery, package and PE version identity,
  Authenticode policy, and verified update-handoff/rollback primitives.
- The new independent `mwfl::scheduler` component provides focused current-user
  application task composition and explicit Task Scheduler management.

### Examples and applications

- Adds focused production examples for Process, IPC, Service, Diagnostics,
  Security, Deployment, and Scheduler.
- Adds the multi-file `supervised_worker` reference application with normal,
  cancellation, timeout, crash, hang, malformed-frame, disconnect,
  log-failure, and unauthorized scenarios.
- Keeps all system mutation behind explicit integration modes and gives every
  example a side-effect-free self-test path.
- Validates 62 compiled repository examples and nine standalone applications
  in the `mwfl` GitHub organization against this release baseline.

### Compatibility

Foundation APIs were provisional in 0.1.9 and have been deliberately refined
for this minor baseline. See `docs/foundation-migration-next.md` for the exact
source migration table. The UI component remains independently acquired, and
applications must rebuild with the same MSVC toolset/runtime configuration;
ABI compatibility is not promised.

System registration and machine mutation remain explicit, idempotent, and
reversible. Runtime components never install services, Event Log sources,
credentials, or scheduled tasks implicitly.

### Downloads

- `mwfl-0.2.0-AMD64.zip`: installed CMake package, libraries, public headers,
  documentation, and notices.
- `mwfl-notepad-0.2.0-windows-x64.zip`: portable Notepad reference application.
- `SHA256SUMS-x64.txt`: SHA-256 checksums for both ZIP archives.

The downloadable packages target VS2026/MSVC x64. Source builds and CI also
cover VS2022 compatibility and ARM64 compilation.
