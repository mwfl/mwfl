## mwfl 0.1.0

The first official public release of Modern Windows Foundation Layer. This
release establishes one clean version baseline containing the complete current
UI, application-support, and Foundation component set.

### Highlights

- Native HWND applications with typed C++20 events, explicit ownership,
  DPI-aware layout, message-loop integration, and raw Win32 escape hatches.
- A WTL/ATL-free window engine using a shared native trampoline,
  `RegisterClassExW`, `CreateWindowExW`, `WM_NCCREATE`, and `GWLP_USERDATA`.
- Native controls, dialogs, docking and document workspaces, graphics, imaging,
  printing, OLE, Shell, Ribbon, MDI, WebView2, and Scintilla components.
- Pinned Microsoft WIL support is available to applications for Win32 RAII and
  scope cleanup without leaking WIL types into mwfl's public API.
- Foundation components for services, processes, bounded local IPC, structured
  diagnostics, security, deployment, and Task Scheduler integration.
- Privacy-conscious minidumps, Authenticode verification, recovery helpers, and
  bounded application update checks.
- 62 compiled examples, copyable application templates, package-consumer
  verification, lifecycle failure injection, GUI self-tests, and coding-agent
  discovery assets.
- Visual Studio 2022 and 2026 support for x64 and ARM64 source builds and
  published binary packages.

### Packages

- `mwfl-0.1.0-AMD64.zip`: installed CMake package, libraries, public headers,
  documentation, licenses, and dependency metadata.
- `mwfl-0.1.0-ARM64.zip`: installed ARM64 CMake package and libraries.
- `mwfl-notepad-0.1.0-windows-x64.zip` and
  `mwfl-notepad-0.1.0-windows-arm64.zip`: portable Notepad reference application.
- `SHA256SUMS-x64.txt` and `SHA256SUMS-arm64.txt`: SHA-256 checksums.

See the repository README and component catalog for setup and API guidance.
