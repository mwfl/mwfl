## mwfl 0.1.2

This usability update adds automatic Windows appearance propagation and makes
the recommended API path clearer across the library and its examples.

### Highlights

- Added automatic system light/dark switching for `WindowBase`, including the
  frame, menus, native descendants, client-area palettes, and custom drawing
  notifications.
- Improved dark GroupBox caption and border rendering so native group titles
  blend cleanly with dark parent backgrounds.
- Added a populated Appearance example covering system, light, dark, backdrop,
  native controls, custom drawing, High Contrast, and live theme changes.
- Standardized examples on retained `SetAppearance()` policy. The raw HWND
  helper is now explicitly named `ApplyWindowAppearanceBestEffort()` so callers
  do not mistake request acceptance for guaranteed DWM support.
- Clarified when `MustInvoke()` should be used to preserve `GetLastError`
  diagnostics from Win32 setup operations.
- Parallelized the release build to reduce package publishing time while
  retaining the full test and package gates.

### Packages

- `mwfl-0.1.2-AMD64.zip`: CMake package and installed public files for
  VS2026/MSVC x64.
- `mwfl-notepad-0.1.2-windows-x64.zip`: portable Notepad reference application.
- `SHA256SUMS-x64.txt`: SHA-256 checksums for both ZIP packages.

Source builds and CI continue to cover x64 and ARM64 with Visual Studio 2022 and
Visual Studio 2026. An ARM64 binary package is not published in this preview.
