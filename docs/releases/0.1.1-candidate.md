# mwfl 0.1.1 release evidence

This record captures candidate and final release evidence gathered on
2026-08-22 for pull request #10 and tag `v0.1.1`.
Hosted validation for candidate commit `f9edf91` completed successfully in the
[CI run](https://github.com/mwfl/mwfl/actions/runs/32610193896) and the
[eight-application downstream run](https://github.com/mwfl/mwfl/actions/runs/32610193917).
The final documentation-only candidate commit `a3ffca7` passed both its
[PR CI run](https://github.com/mwfl/mwfl/actions/runs/32611198824) and
[downstream run](https://github.com/mwfl/mwfl/actions/runs/32611198807) before
merge.

- Windows 10.0.26200, Windows SDK 10.0.26100.0
- Visual Studio 2026 18.8, MSVC 19.51.36252
- CMake 4.3.1-msvc1

## MWFL repository

- Complete VS2026 x64 Debug build succeeded, including public-header probes,
  examples, Agent fixtures, and tests.
- The 201-test Debug suite completed. Nineteen user-profile, desktop, registry,
  DPAPI, GPU, or nested-package tests were denied by the restricted sandbox;
  all nineteen passed when rerun with ordinary Windows user/desktop access.
- The installed-package test passed in 147.98 seconds and covered installed
  package, `FetchContent`, and `add_subdirectory` consumers.
- `mwfl.api_surface`, `mwfl.compatibility_0_1_1`, `mwfl.examples.catalog`, and
  `mwfl.release_metadata` passed.
- After the final 0.1.1 version and warning fixes, the complete VS2026 x64
  Release build succeeded and all 201 Release tests passed in 177.72 seconds;
  its package-consumer gate took 152.72 seconds.
- MSVC static analysis reports no warnings in project-owned source. Remaining
  diagnostics originate in the pinned Microsoft WIL dependency.
