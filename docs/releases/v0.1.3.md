## mwfl 0.1.3

This release establishes the broader Modern Windows Foundation Layer product
direction while giving the existing native UI layer an explicit component
identity.

### Highlights

- Makes `mwfl::ui` the sole public CMake target for the native UI layer across
  build-tree, installed-package, FetchContent, examples, templates, tests,
  documentation, website, and Agent metadata.
- Removes the former generic target completely. Existing consumers must update
  their `target_link_libraries(...)` entry to `mwfl::ui` when moving to 0.1.3.
- Added two compiled CLI examples covering Unicode command routing, stable exit
  codes, `std::jthread`, `std::stop_token`, and cooperative shutdown.
- Added the Windows application foundation roadmap for GUI, Windows Service,
  and CLI hosts, with Service, process, IPC, diagnostics, security, and
  deployment kept as independently requested components.
- Added a Windows Service application design preview defining console-debug,
  SCM-hosted, cancellation, status, management, and cleanup expectations for
  the future `mwfl::service` component.

### Packages

- `mwfl-0.1.3-AMD64.zip`: CMake package and installed public files for
  VS2026/MSVC x64.
- `mwfl-notepad-0.1.3-windows-x64.zip`: portable Notepad reference application.
- `SHA256SUMS-x64.txt`: SHA-256 checksums for both ZIP packages.

Source and CI retain the existing Windows 10+, C++20, x64, and ARM64 design
constraints. The published binary package remains x64 for this preview.
